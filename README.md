# כסף

מעקב הוצאות אישי. אפליקציית PWA בקובץ סטטי — בלי שרת, בלי חשבון, בלי עלות.

## מה זה עושה

- **מזומן בארבע שניות** — סכום, קטגוריה, שמור.
- **צילום מסך → שורות דאטה** — דף אשראי, תנועות בנק, קבלה או מסך של ביט/פייבוקס
  נשלחים ל-Gemini ישירות מהדפדפן וחוזרים מפוענחים ומסווגים.
- **מילון לומד** — תייגת בית עסק פעם אחת, הוא לא יישאל שוב.
- **הוצאות קבועות** — מוגדרות פעם אחת ונרשמות אוטומטית בכל חודש.

## ארבעת המימדים

כל תנועה נושאת ארבעה מימדים, לא רק קטגוריה:

| מימד | ערכים |
|---|---|
| מחלקה › קטגוריה | 12 מחלקות, 90 קטגוריות |
| סוג | קבוע · משתנה · חד-פעמי |
| חיוניות | חיוני · רשות |
| היקף | פרטי · עסקי |

## פינות ישראליות

- **תשלומים** — `3 מתוך 12` נשמר כחיוב חודשי + התחייבות עתידית.
- **תאריך קנייה מול תאריך חיוב** — שתי העמודות נשמרות בנפרד.
- **כפילויות** — אותה עסקה מהארנק ומדף האשראי מזוהה אוטומטית ומסומנת.
- **ביט / פייבוקס / משיכת מזומן** — העברות, לא הוצאות. לא מזהמות את הסטטיסטיקה.

## התקנה

1. פתח את הכתובת בכרום בטלפון → תפריט → **הוספה למסך הבית**.
2. הגדרות → הדבק מפתח Gemini חינמי מ-[aistudio.google.com/apikey](https://aistudio.google.com/apikey).
3. הגדרות → תקציב חודשי (משמש למספר "נשאר להוציא היום").

## פרטיות

- כל הנתונים ב-IndexedDB **על המכשיר בלבד**. אין שרת ואין חשבון.
- מפתח ה-API נשמר מקומית ו**לא נכלל בייצוא**.
- הצילום עצמו כן נשלח ל-Gemini לצורך הפענוח. לצילום רגיש — השתמש ב"הזנה ידנית",
  והתמונה לא עוזבת את המכשיר.
- אין גיבוי אוטומטי בענן. **ייצא JSON מדי פעם** — האפליקציה מזכירה אחרי שבוע.

## מבנה

| קובץ | תפקיד |
|---|---|
| `index.html` | שלד ועיצוב |
| `app.js` | לוגיקה, מסכים, חיווט |
| `taxonomy.js` | מבנה המחלקות — מקור האמת לקטגוריות |
| `db.js` | IndexedDB, מילון לומד, זיהוי כפילויות, ייצוא/ייבוא |
| `ai.js` | פענוח צילומים מול Gemini |
| `sw.js` | עבודה אופליין + קליטת צילומים משותפים |

הוסף `?debug=1` לכתובת כדי לחשוף את `window.__kesef` לאבחון מהקונסולה.
